# CAD_Blocks — housing block library

Parametric library generated by `blocks_build.py`. **97 block DXF files**
(including 27 `A-MODENA-*` modules), intended for the Level 2 sheet set and
reusable in any other housing project.

## Convention (important)

| Item | Value |
|---|---|
| Units | **meters** (`$INSUNITS = 6`), same as the rest of the project |
| Drawing scale | 1:1 real (a toilet is 0.40 × 0.70 m in the block) |
| Insertion point | **(0,0) = $INSBASE**, lower-left corner / hinge |
| Orientation | the block "faces" **+Y** (up) |
| Layer | **0** — inherits color and lineweight from the insertion layer |
| Insertion scale on a sheet | `sheet_scale / 1000` → **1:50 ⇒ 0.02** |

Example: on a 1:50 sheet, a toilet is inserted with `xscale = yscale = 0.02`
and measures 0.40 × 0.70 m = 8 × 14 mm of paper.

## Insert from CADCraft / AutoCAD

```
INSERT
  name: A-INODORO
  file: CAD_Blocks/A-INODORO.dxf      (CADCraft reads its model space)
  point: 3.20,1.45
  scale: 0.02
  rotation: 0/90/180/270
```

The insertion point is the lower-left corner (or the hinge for doors). Rotation
is about `(0,0)`.

## Using the library from Python

`sheet_lib.py` declares the blocks and inserts them:

```python
lam = Lamina(1, 13, "GROUND FLOOR", escala=50)
lam.poner("A-INODORO", tr, 3.20, 1.45, rot=0)
```

`poner()` resolves the insertion scale from the sheet scale. Do not insert
blocks at an arbitrary scale.

## What is in the library

- **Furniture:** beds, sofa, table, chairs, desk, TV module, wardrobe, kitchen.
- **Bathroom:** toilet, bidet, washbasin, shower, bathtub, laundry sink.
- **Openings:** doors, double doors, balcony doors, windows, garage door.
- **Exterior:** trees, car, grill, 1,000 L tank.
- **Services:** electrical outlets, switches, lights, water/gas symbols.
- **Modena modules:** 27 parametric kitchen/closet modules (`A-MODENA-*`).

The machine-readable index is `index.json`; the combined preview is
`catalog.dxf` (with `catalog.png`).

## Rebuilding

```bash
python3 blocks_build.py
python3 blocks_catalog.py
```

`blocks_build.py` writes one DXF per block and `index.json`;
`blocks_catalog.py` writes `catalog.dxf` and the PNG catalog.

> Blocks are 1:1 in meters and drawn on layer `0`. If a block looks wrong when
> inserted, check its base point and orientation before changing the block.
